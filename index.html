How System Works

📡

1. Sensor Collection

Hardware sensors collect body temperature, BP, and Emergency button state directly from patient.

⚡

2. REST API Sync

Sensors send encrypted JSON payloads to PHP Backend API with device API Authentication key.

💾

3. PHP & MySQL Storage

PHP Backend validates payload, stores metrics in MySQL database tables, and detects threshold breaches.

🚨

4. Emergency Alerts

Instant web dashboard popup, audio alarm, and SMS/Email notification dispatched to logged-in user.
