About Project

An end-to-end IoT Health Monitoring Website designed to continuously acquire physiological metrics (Body Temperature and Blood Pressure) via hardware sensors and deliver real-time emergency alert notifications.

🎯 Key Objectives

  • Continuous Health Tracking: Fetch live Body Temperature (°F) and Blood Pressure (mmHg) data from hardware sensors using HTTP REST APIs.
  • Panic Alert Button: Immediate emergency alert detection when patient activates the sensor's physical panic button.
  • User Authentication: Secure OTP-based authentication system using Mobile Number or Gmail.
  • Full Stack Integration: Responsive HTML/CSS/JS web dashboard connected to PHP & MySQL database.

🛠️ Technology Stack

Frontend: HTML5, CSS3, JavaScript (ES6+), Chart.js
Backend: PHP 8+, PDO MySQL Database Handler
Database: MySQL (users, health_data, alerts, api_devices)
Hardware / API: JSON REST Endpoint, ESP8266 / ESP32 Sensor Compatibility

📊 Database Architecture

-- MySQL Database Tables Structure:
1. `users` (id, name, mobile, email, otp, otp_expiry, created_at)
2. `health_data` (id, user_id, temperature, blood_pressure, systolic, diastolic, emergency, created_at)
3. `alerts` (id, user_id, alert_message, alert_type, status, created_at)
4. `api_devices` (id, user_id, api_key, device_name, status, created_at)
